    About this prototype

    Everything here is synthetic. Wren Halloway, her bike co-op, her mom, her garden and all 90-odd notes are invented. No real vault was read to make this. State lives in your browser tab only and resets on reload.

    It imagines Parachute as the memory layer of Uni (Hermes agent + Parachute memory + Buzz chat): one vault, "u·n·i = you and I".

    Real todayNotes with path, content, tags, metadata, wikilinks and typed links; tag parents (life/month under life); write attribution (created_via: app / mcp / api / nostr:<pubkey>); full-text search weighted to titles; semantic search that chunks notes and ranks by best chunk; tag-scoped tokens with expiry.
    ImaginedThe unified folder layout; "why this matched" explanations; Uni proposing links around a frozen capture; a deny-wins privacy boundary for capture/transcript/private; this map and timeline.
    SimulatedEmbeddings and scores (a small concept lexicon standing in for bge-small), latency, voice transcription, and tokens (they're random strings and grant nothing).

    Note classes: capture sacred, never rewritten · ingest imported as-is · derived Uni may rewrite · scaffolding structure (people, projects, views).
