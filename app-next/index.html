Talk to Uni: next

A clickable sketch. One surface, two substrates. Buzz holds the conversations and Parachute holds what you know. The app stops treating them as separate places.

BuzzVaultUni

  • Today: the morning brief, commitments pulled from chats and notes, and what Uni is doing.
  • Stream: captures, notes and messages on one timeline. Tap anything.
  • In a chat, “→ Note” turns a message into a vault note that links back to it.
  • In a note, “Talk about this” opens a thread with the note attached as context.
  • Search is by meaning across both substrates. Try “why did we pause the house”.
  • The ✦ button is voice capture. It is transcribed, filed to the vault, and optionally sent to Uni.
  • The project chips scope everything: channel, notes, people, commitments.

All data is synthetic.
